# supervised-learning

Этот проект посвящен решению задачи регрессии для предсказания стоимости аренды недвижимости. 

Основная цель работы — практическое изучение математических основ машинного обучения через реализацию ключевых алгоритмов «с нуля», без использования высокоуровневых методов обучения из готовых библиотек. 
Репозиторий демонстрирует полный цикл моделирования: 
от первичной обработки сырых данных до валидации результатов.

Архитектура проекта строится на сравнении различных подходов к линейному моделированию. 
Реализованы собственные классы линейной регрессии с использованием аналитического решения (нормальное уравнение) и итеративного метода градиентного спуска. Также разработаны версии моделей с регуляризацией (Ridge, Lasso, ElasticNet) и инструменты для масштабирования признаков (MinMaxScaler, StandardScaler), что позволяет детально контролировать процесс обучения.

На текущий момент выполнен разведочный анализ данных (EDA), включая фильтрацию выбросов и генерацию признаков из текстовых описаний удобств. Проведено сравнительное тестирование самописных алгоритмов с эталонной реализацией из библиотеки scikit-learn с использованием метрик MAE, RMSE и R². Дополнительно исследовано влияние полиномиальных признаков на качество предсказаний.

Проект ориентирован на инженеров, углубляющих знания в алгоритмах машинного обучения, и показывает, как теоретические методы оптимизации применяются к реальным данным. С прикладной точки зрения, разработанные модели могут служить базой для систем автоматической оценки недвижимости или инструментов динамического ценообразования.
